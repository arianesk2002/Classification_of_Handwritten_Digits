# ✋ Classification of Handwritten Digits (MNIST)

> A machine learning project for **classifying handwritten digits (0–9)** using the MNIST dataset.  
> Built with Python and deep learning techniques to demonstrate a full ML pipeline from data preprocessing to prediction.

---

## 📌 Overview

This project implements a complete workflow for **handwritten digit recognition** using the famous MNIST dataset.

The system is capable of:
- Training a model on labeled digit images
- Evaluating performance on unseen test data
- Predicting digits from custom input images

> *Goal: Build a simple but effective digit classification system using SVD techniques.*

---

## ✨ Features

- ✔️ Handwritten digit classification (0–9)
- ✔️ MNIST dataset integration
- ✔️ Data normalization & preprocessing
- ✔️ Train/Test evaluation pipeline
- ✔️ Jupyter Notebook-based experimentation

---

## 📊 Dataset

The project uses the **MNIST dataset**, which contains:

- **60,000 training images**
- **10,000 test images**
- Grayscale images of size **28×28**
- **10 classes (digits 0–9)**

📎 Dataset source: http://yann.lecun.com/exdb/mnist/

> Each image represents a handwritten digit written by humans and normalized for machine learning tasks.
